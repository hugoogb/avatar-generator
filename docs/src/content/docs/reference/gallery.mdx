## Choosing a style

- **Initials / Geometric / Rings / Gradient / Abstract** — no personal features; good for abstract identity
- **Marks** — logo-like badges; good for organizations, workspaces and teams
- **Robots** — good for accounts that are not people: bots, AI agents, service accounts and API keys
- **Portraits** — calm single-colour people; good for professional and business tools
- **Pixels / Faces / Illustrated / Anime / Emoji / Animals / Creatures** — face or character-based; good when you want an avatar that reads as a "person" or mascot

All fifteen styles share the same base options (`seed`, `size`, `colors`,
`square`, `transparent`, `border`, `rotate`, `flip`, `scale`). See the [API
Reference](/reference/avatar/) for style-specific options.
