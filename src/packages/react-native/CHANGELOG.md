# @avatar-generator/react-native

## 3.3.0

### Minor Changes

- a47d321: New package: `@avatar-generator/react-native` renders `Avatar` and `AvatarGroup` through `react-native-svg`, for React Native 0.77 or later and Expo. `theme: "auto"` follows the device's colour scheme and contrast setting. Animation is not supported, because `react-native-svg` does not run CSS.
